UPDATE AN EXISTING INSTALL
1. Extract this zip somewhere (never upload the zip itself — Pages does not unzip).
2. github.com -> your lifeos repo -> Add file -> Upload files.
3. Drag in ALL files above, INCLUDING the assets folder. Same names overwrite.
4. Commit changes. Wait 1-2 minutes.
5. Close the app/tab, reopen your Pages URL, reload TWICE (old worker first, new worker second).
   Never clear "cookies and site data" (that deletes the vault).
6. Check: sidebar on the left, v3 badge, Today room opens first, Archive loads.

FIRST-TIME INSTALL
New repo (Public) -> upload the same files -> Settings -> Pages -> Deploy from branch ->
main / (root) -> open https://USER.github.io/lifeos/ in Edge -> menu -> then INSTALL.
file:// never installs (must be an https URL).
