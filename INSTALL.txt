LIFE//OS v4.0 — INSTALL / UPDATE (GitHub Pages)
=============================================
Upload these 7 files. Nothing else. No assets folder, no images to drag —
the artwork is baked into index.html itself.

  index.html        (the app — big file, contains everything including art)
  manifest.json
  sw.js
  icon.svg
  icon-192.png
  icon-512.png
  INSTALL.txt

UPDATE (2 minutes)
1. Extract this zip somewhere (never upload the zip itself).
2. github.com -> your lifeos repo -> Add file -> Upload files.
3. Drag in ALL 7 files. Same names overwrite the old ones.
4. Commit changes. Wait 1-2 minutes.
5. Close the app/tab, reopen your Pages URL, reload TWICE
   (first reload gets the new worker, second shows the new build).
   Never clear "cookies and site data" — that deletes the vault.
6. Check: v4.0 badge next to LIFE//OS, poster wall shows IMAGES now,
   Today opens first, Archive opens.

If you earlier uploaded an "assets" folder and it shows broken files in the
repo, you can leave it there (nothing references it) or delete it via each
file's page -> trash icon.

NEW IN v4.0 — THE PHONE APP

    with big thumb-sized buttons, a full-screen ROOMS hub with every room as a tile

NEW IN v3.8
  - Sync can no longer half-pair a device. If the cloud vault was sealed with a
    different passphrase than this device, AUTO sync refuses to mix them and says so
    instead of copying data onto the wrong key (the bug that caused "wrong passphrase
    / nothing happens" lockouts). PULL now warns it replaces the passphrase too.
    Service worker cache bumped to lifeos-v10.

NEW IN v3.7
  - Cloud sync tells the truth. If Google refuses a sync call, the app now shows the
    real error text (e.g. "Drive API has not been used in project ...") instead of a
    fake success. Fixed: "pushed (first sync)" no longer appears when the upload
    actually failed. Service worker cache bumped to lifeos-v9.

NEW IN v3.6

    reconnects silently in the background (Google sign-in with no popup when it is
